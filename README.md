# Pancasila Chronicles

JRPG 2D edukasi Pancasila bergaya Suikoden 2. Dibuat dengan HTML5 Canvas + Vanilla JS + Firebase.

## 🚀 Cara Upload ke GitHub Pages

1. **Fork / Clone repo ini** atau copy semua file ke repo baru Anda.
2. **Setup Firebase** (lihat bawah) → isi `config.js`.
3. **Push ke GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/USERNAME/pancasila-chronicles.git
   git push -u origin main
